# DiversyFund

> DiversyFund is a San Diego based private-markets investment platform that packages institutional-style fixed income and multifamily real estate offerings for individual accredited investors. Formed in 2016 and qualified under SEC Regulation A+, the firm sponsors, develops and manages its own funds rather than acting as a broker. DiversyFund publishes no public API, developer portal, SDK, or machine-readable API contract; all investor activity happens inside an authenticated portal.

## APIs

DiversyFund publishes no public API. As of 2026-08-04 there is no developer portal,
no API reference, no OpenAPI/Swagger/GraphQL/AsyncAPI document, no MCP server, no
A2A agent card, no first-party SDK in any public package registry, and no
`/.well-known/` discovery document on any DiversyFund host. Every route on the
investor portal — including `/api/*` — redirects anonymous requests to WorkOS
AuthKit for authentication. See `review.yml` in this repository for the full probe
evidence table.
